## Sky layers

Each layer is turned on and off independently:

| Option | Key |
|---|---|
| Constellations | |
| Names | |
| Milky Way | |
| Ground | |
| Azimuthal grid | `Z` |
| Equatorial grid | `E` |
| Ecliptic | `4` |
| Meridian | `6` |

The **Milky Way brightness** control adjusts its intensity.

## Landscape

Choose the horizon: countryside with hills, village, mountains and forest, or no landscape (flat horizon).

## Projection

Stereographic, equidistant (fisheye) or perspective. See [Views and time](vistas-y-tiempo.md).

## Shadow guide and Danjon

The **Shadow guide** and the lunar eclipse darkness control (**Danjon L**) are described in [Events and eclipses](eventos-y-eclipses.md).

## Trajectories

**Trajectory range** and **Trajectory labels**. See [Trajectories and geometries](trayectorias-y-geometrias.md).

## Language and accessibility

- **Language:** English or Spanish. It is remembered in your browser.
- **Text size:** three sizes (A A A).
- **Panel opacity.**
- **Night mode** (`N`): red filter to preserve night vision.
- Panels can be minimized and moved; their position is remembered.

## Developer view

**JSON snapshot** adds a `</>` button to every card with the engine's live JSON. See [Objects and cards](objetos-y-fichas.md).

## What is stored in your browser

Language, last location, your interface preferences and the panel positions, in the browser's local storage. None of it is sent to any server. To delete it, clear the site data from your browser settings. More in **About** (the logo in the top-left corner).
