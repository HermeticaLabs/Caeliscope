## Mouse

| Action | Result |
|---|---|
| Drag | Look around the sky (on the globe, it turns it). |
| Wheel | Zoom in or out. |
| Click an object | Opens its card. |
| Double-click an object | The camera follows it. |
| Click on the globe | Moves the location pin. |

## Keyboard

| Key | Function |
|---|---|
| `H` | Hides or shows the panels. |
| `Space` | Pauses or resumes time. |
| `Z` | Azimuthal grid. |
| `E` | Equatorial grid. |
| `4` | Ecliptic. |
| `6` | Meridian. |
| `T` | Follows the selected object. |
| `C` | Centers the view on the selected object. |
| `L` | Back to the globe to pick another location. |
| `F` | Full screen. |
| `N` | Night mode (red filter). |
| `Esc` | Closes cards and windows. |

On the opening screen, any key or click continues. On the globe, `Enter` opens the sky of the marked location.

## Touch screen

| Gesture | Result |
|---|---|
| Drag with one finger | Look around. |
| Pinch with two fingers | Zoom in or out. |
| Tap an object | Opens its card. |
| Double-tap an object | The camera follows it. |

Small objects can be tapped without having to hit the exact pixel.

> Tip: if you cannot see the controls, press `H`; the panels may be hidden.
