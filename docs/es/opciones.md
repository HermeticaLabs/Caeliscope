## Capas del cielo

Cada capa se activa y desactiva de forma independiente:

| Opción | Tecla |
|---|---|
| Constelaciones | |
| Nombres | |
| Vía Láctea | |
| Suelo | |
| Cuadrícula azimutal | `Z` |
| Cuadrícula ecuatorial | `E` |
| Eclíptica | `4` |
| Meridiano | `6` |
| Lunas | |

El control **Brillo de la Vía Láctea** ajusta su intensidad.

## Paisaje

Elige el horizonte: campo con cerros, pueblo, montañas y bosque, o sin paisaje (horizonte plano).

## Proyección

Estereográfica, equidistante (ojo de pez) o perspectiva. Ver [Vistas y tiempo](vistas-y-tiempo.md).

## Guía de sombra y Danjon

La **Guía de sombra** y el control de oscuridad del eclipse lunar (**Danjon L**) se describen en [Eventos y eclipses](eventos-y-eclipses.md).

## Trayectorias

**Alcance de la trayectoria** y **Etiquetas de trayectoria**. Ver [Trayectorias y geometrías](trayectorias-y-geometrias.md).

## Idioma y accesibilidad

- **Idioma:** español o inglés. Se recuerda en tu navegador.
- **Tamaño del texto:** tres tamaños (A A A).
- **Opacidad de los paneles.**
- **Modo nocturno** (`N`): filtro rojo para conservar la visión nocturna.
- Los paneles se pueden minimizar y mover; su posición se recuerda.

## Vista para desarrolladores

**Snapshot JSON** añade a cada ficha el botón `</>` con el JSON en vivo del motor. Ver [Objetos y fichas](objetos-y-fichas.md).

## Qué se guarda en tu navegador

Idioma, última ubicación, tus preferencias de interfaz y la posición de los paneles, en el almacenamiento local del navegador. Nada de eso se envía a ningún servidor. Para borrarlo, elimina los datos del sitio desde la configuración del navegador. Más en **Acerca de** (logotipo de la esquina superior izquierda).
