## Ratón

| Acción | Resultado |
|---|---|
| Arrastrar | Mira alrededor del cielo (en el globo, lo gira). |
| Rueda | Acerca o aleja. |
| Clic en un objeto | Abre su ficha. |
| Doble clic en un objeto | La cámara lo sigue. |
| Clic en el globo | Mueve el marcador de ubicación. |

## Teclado

| Tecla | Función |
|---|---|
| `H` | Oculta o muestra los paneles. |
| `Espacio` | Pausa o reanuda el tiempo. |
| `Z` | Cuadrícula azimutal. |
| `E` | Cuadrícula ecuatorial. |
| `4` | Eclíptica. |
| `6` | Meridiano. |
| `T` | Sigue al objeto seleccionado. |
| `C` | Centra la vista en el objeto seleccionado. |
| `L` | Vuelve al globo para elegir otra ubicación. |
| `F` | Pantalla completa. |
| `N` | Modo nocturno (filtro rojo). |
| `Esc` | Cierra fichas y ventanas. |

En la pantalla inicial, cualquier tecla o clic continúa. En el globo, `Enter` abre el cielo de la ubicación marcada.

## Pantalla táctil

| Gesto | Resultado |
|---|---|
| Arrastrar con un dedo | Mira alrededor. |
| Pellizcar con dos dedos | Acerca o aleja. |
| Tocar un objeto | Abre su ficha. |
| Doble toque en un objeto | La cámara lo sigue. |

Los objetos pequeños se pueden tocar sin necesidad de acertar el píxel exacto.

> Consejo: si no ves los controles, pulsa `H`; puede que los paneles estén ocultos.
